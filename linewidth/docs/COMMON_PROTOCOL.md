# 선폭 측정 공통 기준

업데이트: 2026-11-17. 세 측정 코드(UNet, canny, threshold)와 평가 코드가 모두 이 기준을 따른다.
기준값은 `linewidth/team_protocol.py` 한 파일에만 있다.

## 측정 기준

| 항목 | 기준 |
|---|---|
| 입력 | 표시가 없는 원본 PNG. 임의 resize 금지 |
| 좌표 | native 픽셀 (2배 중복 저장된 캡처는 중복을 걷어낸 좌표) |
| 보정값 | `1 native px = 0.1592 µm` |
| 측정 종류 | 항상 `line`, `gap`. 숫자 1/2/3으로 고르는 메뉴는 없다 |
| 경계 | 빨간 sidewall 띠의 **안쪽 끝** (빨간색이 끝나고 line/gap 색이 시작되는 곳) |
| line | 이웃한 두 sidewall 사이 구간 중 더 밝은 쪽. 마주 보는 두 안쪽 끝 사이 거리 |
| gap | 나머지(더 어두운) 구간. 마주 보는 두 안쪽 끝 사이 거리 |
| Y 위치 | native 높이의 `25%, 45%, 65%` (lt/rb 사진의 둥근 끝을 피한 위치) |
| 측정 범위 | 사진(또는 ROI) 양옆 3% 를 뺀 영역에서 sidewall 두 개 사이에 온전히 들어온 모든 구간 |

```text
y_native = round((native_height - 1) × fraction),  fraction = 0.25, 0.45, 0.65
```

경계를 안쪽 끝으로 잡으므로 `line + gap + 2 × sidewall ≈ 20 µm` (패턴 주기)이고,
line·gap 값은 sidewall 가운데를 경계로 볼 때보다 약 0.9 µm 작다. 판정 기준(pn ≤ 8 µm 등)을
적용할 때 이 차이를 고려한다.

## 일반 측정과 성능 평가의 차이

| | 일반 측정 (대시보드) | 성능 평가 |
|---|---|---|
| 대상 | 양옆 3% 를 뺀 모든 line·gap | 화면 중앙에 가장 가까운 5개씩 (`L1-L5`, `G1-G5`) |
| 출력 | `metrology/unet_metrology.py` 의 공통 JSON | `*_predictions.csv` (`CSV_FORMAT.md`) |
| 용도 | 공정 평균, 판정 | 사람 정답과 1:1 비교 |

측정 알고리즘(경계를 찾는 코드)은 두 경우가 같고, 어떤 대상을 고르느냐만 다르다.

## 성능 평가 방법 (2026-11 기준)

| 지표 | 데이터 | 좋은 방향 |
|---|---|---|
| 정확도 `test/mae_um` | 노트북2 15장, 사람 정답 450개 (보정에 쓰지 않은 사진) | 낮을수록. 단 사람끼리 차이(약 0.22 µm)보다 작으면 의미 없음 |
| 반복성 `stability/repeat_target_sd_um` | 같은 위치 3회 촬영 (안정성 검사, 중앙끼리 비교) | 낮을수록 |
| 조명 민감도 `stability/lighting_image_mean_range_um` | 같은 위치 밝기 3단계 (조명 비교) | 낮을수록 |
| 성공률 `stability/success_rate` | 위 안정성 사진 27장 (이물·얼룩 많은 b 샘플 포함) | 높을수록 |
| 소요 시간 `test/runtime_median_ms` | 같은 PC, CPU, 첫 장 제외 | 낮을수록 |

- 설정값 보정은 노트북1 15장으로 했다. 결과적으로 바꾼 값은 없다 (UNet 확률 임계값 0.50,
  canny 보정 0, threshold 경계 비율 0.57).
- 결과는 DagsHub MLflow `IDA_Width_Measurement` 실험에 방법별 Run 으로 기록되어 있다.

| 방법 | 정확도 (µm) | 반복성 (µm) | 조명 (µm) | 성공률 | 시간 (ms) |
|---|---|---|---|---|---|
| UNet | 0.285 | 0.041 | 0.45 | 100% | 1039 |
| canny | 0.345 | 0.041 | 0.13 | 90% | 174 |
| threshold | 0.214 | 0.062 | 0.33 | 91% | 163 |

정확도는 세 방법 모두 사람끼리 차이 수준이라 순위를 가르지 못한다. 결함이 많은 사진에서도
측정되는 UNet 을 대시보드용으로 선택했다. UNet 은 아주 밝은 사진에서 값이 커지므로 촬영 밝기를
일정하게 유지한다.
