# Roadmap

## 1. 데이터셋

- 이미지와 라벨 구조 정리
- wafer, die, 촬영 위치 정보 정리
- 라벨 기준 검토
- 학습·검증·평가 데이터 분할

## 2. CD 측정

- 패턴 영역 검출과 이미지 전처리
- edge와 line/gap 측정 방법 개발
- 반복 측정 결과 분석
- calibration 확보 후 물리 단위 변환

## 3. 결함 검출

- 결함 유형과 라벨 기준 정의
- 결함 데이터 annotation
- baseline 모델 학습과 평가
- CD 측정 결과와 결함 정보 연계

## 4. 결과 시각화

- wafer map 기반 검사 결과 표시
- die와 이미지 상세 결과 확인
- CD 분포와 결함 현황 시각화
- 검토가 필요한 이미지 관리
