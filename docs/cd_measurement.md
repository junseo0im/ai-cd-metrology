# CD 측정

## 배경

반도체 패턴의 선폭은 노광과 현상 결과, 공정의 균일성을 확인하는 주요 지표입니다. 현미경
이미지를 사람이 한 장씩 측정하면 많은 시간이 필요하고, 측정 위치와 기준에 따라 결과가
달라질 수 있습니다.

선폭 측정을 자동화하면 여러 이미지에 동일한 기준을 적용하고, wafer·die·촬영 위치에 따른
CD 분포를 빠르게 비교할 수 있습니다. 이를 통해 공정 변화를 정량적으로 확인하고 추가 검토가
필요한 패턴을 찾는 데 활용할 수 있습니다.

## 목표

광학 현미경 이미지에서 반복되는 반도체 패턴의 경계를 찾고 line과 gap의 폭을 측정합니다.
현재는 여러 영상처리 알고리즘을 비교하여 데이터에 적합한 baseline을 선정하는 단계입니다.

## 측정 대상

CD 측정을 시작하기 전에 이미지에서 어떤 영역을 line과 gap으로 정의할지 확인해야 합니다.
이를 위해 패턴 설계 정보와 실제 이미지의 밝고 어두운 영역이 어떻게 대응하는지 정리할
예정입니다.

측정이 어려울 정도로 패턴이 손상된 이미지는 임의의 측정값을 생성하지 않고 측정 불가로
구분합니다.

## 알고리즘 비교

특정 방법을 미리 확정하지 않고 여러 classical CV 알고리즘을 동일한 이미지와 위치에서
비교합니다.

초기에는 다음과 같은 방법을 검토합니다.

- 밝기 임계값을 이용한 경계 검출
- 밝기 변화량을 이용한 edge 검출
- 반복 패턴의 주기성을 이용한 측정

비교 결과를 바탕으로 초기 baseline 알고리즘을 선정합니다.

## 평가 기준

- **설계값과의 차이**: 측정한 CD가 설계 치수와 얼마나 차이 나는지 확인합니다.
- **수동 측정값과의 차이**: 사람이 측정한 결과와 자동 측정 결과가 얼마나 일치하는지
  확인합니다.
- **반복 측정 편차**: 같은 위치를 반복 촬영하거나 측정했을 때 결과가 안정적인지 확인합니다.
- **측정 성공률**: 정상적으로 CD를 계산할 수 있는 이미지의 비율을 확인합니다.
- **처리 시간**: 이미지 한 장을 측정하는 데 걸리는 시간을 비교합니다.

설계값과의 차이는 패턴이 설계 의도에서 벗어난 정도를 의미합니다. 수동 측정값과의 차이는
자동 측정 결과의 일치도를 확인하기 위한 기준이며, 수동 측정값 자체에도 측정 오차가 있을 수
있습니다.

## 필요한 정보

- 설계 CD와 pitch
- 이미지의 line과 gap 영역에 대한 정의
- 현미경 배율과 pixel calibration 정보
- 동일 위치의 수동 측정 결과
- 가능하다면 동일 위치를 반복 촬영한 이미지
